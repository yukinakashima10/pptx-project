# プレゼン資料作成ガイドライン（ChoQi / チョキ テンプレート複製方式）

## 1. 基本方針・作成プロセス
- **原則ルール**: スライドや表をゼロから描画せず、`templates/チョキ_テーマ.pptx` を雛形として読み込み、テキスト・数値のみをプログラムで更新する。
- **デザイン維持**: 元ファイルで定義されたカラーパレット、表スタイル、フォント設定（メイリオ等）、レイアウト位置を100%継承する。

## 2. レイアウト＆スライド構造
- **スライドサイズ**: 16:9（ワイドスクリーン）
- **基本構成**: 左右2カラム構造
  - **左カラム**: 定性考察テキスト（`[事業名]：[要因分析コメント]` の形式）
  - **右カラム**: 定量財務データテーブル（予算・実績・見込・差異）

## 3. 自動化スクリプト実装ルール（python-pptx）
1. `prs = Presentation('templates/チョキ_テーマ.pptx')` でベースファイルを読み込む。
2. 既存の `shape` や `cell.text_frame.paragraphs[0].runs[0]` のテキストプロパティを書き換えることで、元の文字装飾・配色を破壊せずに更新する。
3. 生成物は `outputs/` フォルダ配下に保存する。
